Factory Inventory Management System

Full-stack demo: Vue 3 frontend, FastAPI backend, in-memory data loaded from JSON. No database.

System architecture

Frontend

Vue 3 + Vite · localhost:3000
  • Vue Router: 6 views
  • useFilters composable holds shared filter state
  • api.js wraps all axios calls
  • Custom SVG charts, i18n (en/ja)

JSON
query params

Backend

FastAPI + Uvicorn · localhost:8001
  • REST endpoints under /api
  • Pydantic models validate responses
  • Filtering done in Python lists
  • CORS open to all origins (dev only)
→load at
startup

Data

JSON files in server/data/
  • Loaded by mock_data.py
  • Held in memory; changes are lost on restart
  • 7 files: inventory, orders, demand, backlog, spending, transactions, purchase orders

Data flow

  1. The user changes one of four filters: Time Period, Warehouse, Category, Order Status (useFilters.js).
  2. A view watches the filter refs and calls a method in client/src/api.js.
  3. Axios sends GET /api/...?warehouse=&category=&status=&month= to port 8001.
  4. FastAPI runs apply_filters / filter_by_month over the in-memory lists (months and quarters like Q1-2025 are supported).
  5. Results pass through Pydantic response_model validation and return as JSON.
  6. The view stores raw data in refs, derives KPIs and chart series in computed properties, and renders SVG and CSS Grid.
